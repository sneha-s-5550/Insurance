# Insurance Management System

## 📌 Description
This is an Insurance Management System developed to manage insurance policies, customers, and claims efficiently. The system helps users to apply for policies, track details, and manage records digitally.

## 🚀 Features
- User registration and login
- Add and manage insurance policies
- Customer details management
- Policy approval system
- Claim request and tracking
- Admin dashboard

## 🛠️ Technologies Used
- Python
- Django
- HTML
- CSS
- Bootstrap

## ▶️ How to Run
1. Clone the repository
2. Go to project folder
3. Install dependencies:
   pip install -r requirements.txt
4. Run the server:
   python manage.py runserver

## 📂 Project Structure
- insurance/ → main project folder
- app/ → application logic
- templates/ → HTML files
- static/ → CSS, JS, Images
